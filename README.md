# AI-Nexus

AI-Nexus 是一个全新的 Agent 平台，它借鉴了 Aura 的经验并进行了全面的升维。
该项目致力于：
1. **全面适配 Gemini API**：放弃本地大模型的高昂性能开销，利用云端强劲的算力。
2. **专注技能（Skill）编排与调度**：核心架构围绕技能流转设计。
3. **个人知识库与全能助手**：面向个人使用场景，打造高度定制化的超级数字助手。
